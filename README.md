# MayoChord

**在线使用：<https://yisoragoto.github.io/mayochord/>**

MayoChord 是一个连接 MIDI 键盘练和弦的网页应用。目标是让你看到和弦名就能不假思索地弹出来，在和弦之间流畅切换，并且记得住。

它用间隔重复（FSRS）安排复习：快忘的时候才让你复习，已经熟的不浪费时间。每天打开"今天"，按顺序做完系统排好的任务就行。

> 开发中。目前完成到 M4（节拍器与跟拍弹进行），正在做 M5（听辨与读谱）。进度见下方"路线图"。

## 需要什么

- **电脑上的 Chrome 或 Edge**。网页通过 Web MIDI 读取键盘，Safari 和 iPhone/iPad 上的浏览器都不支持 Web MIDI。
- **一台 MIDI 键盘**，用 USB 连接电脑。开发时用 Roland JUNO-D7 实测过；其他 USB MIDI 键盘也可以用。
- 没有键盘也能体验：可以用屏幕上的键盘（鼠标点或触摸屏）或电脑键盘作答。

## 怎么用

1. 打开网址，点"连接 MIDI 设备"，在浏览器弹窗里允许访问 MIDI。
2. 第一次使用建议到"设置"里做一次**八度校准**：按一下中央 C。琴上的 OCTAVE / TRANSPOSE 改过时，弹的音会整体偏移，校准后能自动纠正。要跟节拍器练习的话，再做一次**延迟校准**。
3. 回到"今天"，按顺序做任务。
4. 想自己选内容练，用"自由练习"（和弦练习，或跟拍弹进行）；想查某个和弦怎么按，用"和弦库"。

所有数据都只保存在你的浏览器里（IndexedDB），不会上传到任何服务器。换浏览器或清除网站数据后记录会丢失。导出/导入功能在后续版本加入。

## 功能

- **今天**：每天自动排好任务——热身、到期复习、新课，按设置的每天时长安排。可以跳过任务，新课可以换一个。
- **知识图谱**：18 个主题，从认识键盘到丸サ進行，显示先修关系和每个主题的状态（未解锁、可学习、学习中、已掌握、需复习）。
- **课程**：讲解示范 → 引导练习 → 独立练习 → 掌握检查。已经会的可以直接做掌握检查。
- **隐式复习**：复习难的主题时，它包含的简单主题也算复习过，不用重复练。
- **XP 与连续天数**：约 1 分钟专注练习 = 1 XP，乱按不计。
- **认音名、音程**练习，转位（斜杠和弦）按最低音判定。
- **看名弹和弦**：显示和弦名，在琴上弹出来。可以任意转位，也可以要求按参考键位弹。
- **和弦切换**：先弹"从"和弦，再尽快换到目标和弦，专门练两个和弦之间的切换。
- **自动判定和评分**：
  - 根据对错、反应时间、和弦的音是否同时落下自动打分，不用自己评"记住没有"。
  - 弹错时标出多按的音和少按的音。
  - 超时或弹错后才显示键位，先让你自己回忆。
- **难度自动调整**：根据最近的正确率自动调整时限，让正确率保持在 85% 左右。
- **跟拍弹进行**：节拍器数完预备拍后，跟着拍子弹一整条进行（内置进行或自己输入的和弦序列）。实时显示每个和弦对不对、早了还是晚了多少毫秒；结束后显示节拍偏差分布和稳定性。支持 16 分音符先行切分。
- **声部进行图**：用连线标出前后两个和弦里哪些音不动、哪些音移动了半音或全音。
- **延迟校准**：跟着节拍器敲 16 下，自动扣除声音和按键之间的固定偏差。
- **和弦库**：每个和弦的键位（左右手、指法）、组成音、半音公式（例如 Am = A +3 C +4 E）、五线谱、播放，还可以在琴上试弹。
- **MIDI 监视**：实时显示按下的音、通道、力度和识别出的和弦名，可以导出原始数据。
- **白天 / 夜间两种外观**，手机竖屏也能用。

## 开发

需要 Node.js 22 以上和 pnpm 12。

```bash
pnpm install
pnpm dev          # 开发服务器 http://localhost:5173/mayochord/
pnpm lint         # Biome 代码检查
pnpm typecheck    # TypeScript 类型检查
pnpm test         # 单元测试
pnpm coverage     # 单元测试 + core 覆盖率（门槛 90%）
pnpm build        # 构建到 apps/web/dist
pnpm e2e          # 端到端测试（Playwright，用模拟的 MIDI 输入）
```

推送到 `main` 后，GitHub Actions 会跑完整检查，并自动部署到 GitHub Pages。

### 目录

```
packages/core      纯 TypeScript 的核心逻辑：乐理、和弦识别与判定、评分、调度、知识图谱（不依赖浏览器）
packages/content   内容包格式（Zod 校验）和内置内容：和弦、键位、进行、课程
apps/web           网页应用：React 19、Vite、TanStack Router、Tailwind CSS、Dexie
```

需求与设计见 [MAYOCHORD_SPEC.md](MAYOCHORD_SPEC.md)，开发约定与 JUNO-D7 实测记录见 [CLAUDE.md](CLAUDE.md)。
